LOOGOOTEE METHODIST YOUTH JEPORDY — GITHUB EDITION

1. Extract this ZIP.
2. Upload the extracted files to the top level of your GitHub repository.
3. Enable GitHub Pages: Settings > Pages > main branch > /(root).
4. The single-screen game is ready. No ChatGPT login is needed.
5. For the live phone host, open SETUP.html and follow the Firebase instructions.
   The included design works with Firebase's free Spark plan.

Phone syncing needs your Firebase project, one host login, and the supplied
security rules. The default configuration keeps it off until setup is complete.

README.md contains the full guide. The development/ folder includes source
and tests for later editing; it is not needed for normal game play.
